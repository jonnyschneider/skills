# jonny-skills

Public skills for Claude Code.

## Installation

Skills can be installed individually by symlinking to `~/.claude/skills/`:

```bash
# Clone the repo
git clone https://github.com/jonnyhump/jonny-skills.git ~/Dev/jonny-skills

# Symlink a skill
ln -s ~/Dev/jonny-skills/skills/md-to-docx ~/.claude/skills/md-to-docx
```

## Available Skills

| Skill | Description |
|-------|-------------|
| [md-to-docx](skills/md-to-docx/) | Convert markdown to beautifully styled Word documents |
